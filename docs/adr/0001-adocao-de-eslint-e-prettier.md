# ADR 001: Adoção de ESLint e Prettier

**Data:** 2021-11

## Contexto

O projeto precisava reduzir inconsistência de código e melhorar revisão.

## Decisão

Adotar ESLint para qualidade estática e Prettier para formatação automática.

## Consequências

Código mais padronizado; mais regras e ajustes no fluxo de desenvolvimento.
