# ADR 004: Uso de Storybook para Documentar Interface

**Data:** 2022-02

## Contexto

Componentes reutilizáveis estavam crescendo e faltava isolamento para desenvolvimento visual.

## Decisão

Adotar Storybook como ambiente de documentação e validação de interface.

## Consequências

Melhor reuso e visualização; mais custo de manutenção paralela.
