# ADR 005: Adoção de Tailwind CSS e Redução de Style Modules como Padrão Principal

**Data:** 2022-02

## Contexto

Em 2021 o projeto usava style modules, mas o time buscava mais velocidade e consistência visual.

## Decisão

Adotar Tailwind CSS como estratégia principal de estilização.

## Consequências

Ganho de produtividade e padronização; classes mais densas no markup e curva de aprendizado.
