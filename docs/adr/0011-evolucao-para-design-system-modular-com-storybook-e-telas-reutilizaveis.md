# ADR 011: Evolução para Design System Modular com Storybook e Telas Reutilizáveis

**Data:** 2024-12

## Contexto

A interface cresceu em atoms, molecules, screens e utilitários compartilhados.

## Decisão

Consolidar uma organização orientada a Design System com documentação e testes de componentes.

## Consequências

Maior reuso e consistência; necessidade de governança sobre nomes, camadas e contratos.
